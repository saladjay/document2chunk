# 0001 — 含合并格表格的嵌入输入维持原样 HTML

**Status**: accepted（2026-09-22）

外部文献与业界实践普遍建议「不要把原始 HTML 标签直接喂给 embedding 模型，转换（如 Markdown/摘要）后再嵌入」；但 2026-09 本地双臂实验（bge-m3 与 qwen3-vl-embedding-8b，经 112 研发中心中转，红头公文语料真池 10,305 chunk、预登记判据）证明：**含合并格表格 chunk 原样嵌出 HTML（`export/_helpers.py` 三分流现状）在两个生产候选模型上不被任何替代序列化（展开管道表/KV 平铺/XML/前置标题/NL 摘要）显著超过，多数替代显著更差**，故维持现状不改。完整证据链与数据：`Document2Chunk-表格嵌入格式-裁定与实验设计.md` §7（判据、四发现、有效性注记）。

## Considered Options

- **V2 展开管道表 / V3 KV 平铺 / V5 HTML+前置标题**：双臂均不优于现状（−2 至 −11pp @10）。
- **V4 XML**：qwen 上唯一正增（+2.2pp，未过 +3pp 预登记线）且在 bge 上 −14pp——若未来 embedding 选型落到 qwen3-vl-embedding-8b，此选项重开。
- **V6 NL 摘要进向量（Unstructured 式业界实践）**：双臂皆崩（−17/−28pp）。公文表格查询以实体/数值/日期为靶，摘要丢失定位锚点；该实践不迁移到本场景。

## Consequences

- **换 embedding 模型 = 本实验必须重跑**：格式×模型强绑定已被本地实证（与 arXiv 2604.24040 一致），XML 在 qwen 最好、在 bge 倒数。实验资产在 `_embedlab/`（查询集、真池、评测器，背景池嵌入可缓存复用）。
- 真实查询日志到位后须按 issues8 A 做校准（生成查询集 vs 日志集的格式排序 Kendall τ）；人工抽查清单在 `_embedlab/gen/spotcheck_relay.md`。
- 本 ADR 只裁决「嵌入输入格式」；表格承载格式（HTML 保 colspan/rowspan）的结构保真依据见同报告 §2/§3（规格级证据），Excel 轨A 行级 KV 不受本 ADR 影响。
