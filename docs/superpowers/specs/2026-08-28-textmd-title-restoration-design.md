# .md/.txt 缺失标题复原（text_titles）设计

日期：2026-08-28　状态：已实现并验收

## 背景与目标

serve（/parse-pdf）对 `.md` 原为字节直通、`.txt` 仅转码，`result.md` 无任何标题结构。
这些文件来自网页转存（markdownify）与 OCR，普遍缺失 `#` 标题——层级以粗体
`**`、中文编号（`一、`/`（一）`/`第X章节条`）表达，甚至与正文粘连在同一段。

目标：在早退路径上把标题层级复原为 `#`~`####`，产出**无损**（除标题标记与
空白外一字不丢）、**幂等**（重入不二次改写）的 `result.md`。

领域知识来源：`WebCrawler/chunker/structure.py` 的样式层级表
（cn_major=章级、cn_minor=节级、article=条级、数字枚举不入层级）。与 chunker
的差异：chunker 只看块首行（对 OCR txt 标题在块中间的形态失效）；其
`RE_CN_MAJOR` 带 `$` 锚点导致粘连拆分是死代码；其目录识别依赖页码后缀
（OCR 目录行常无）。本模块逐行扫描、真正实现粘连拆分、新增目录区识别。

## 架构

```
serve.parse_to_files / parse_to_zip
  └─ .md 早退：_decode_text（UTF-8→GB18030 回退，剥 BOM；失败→字节直通）
            → text_titles.restore_titles → UTF-8 无 BOM 写 result.md
  └─ .txt 早退：_decode_text → restore_titles → UTF-8 无 BOM
```

- `text_titles.py`：纯函数 `restore_titles(text) -> str`，无 IO；serve 侧
  `_restore_text` 兜底任何异常回退原文（复原失败绝不影响解析）。
- `_minimal_doc` 契约不变（md/txt 仍不进 extractor/postprocess，不产 IR）。
- CLI（parse_to_files）与 zip 模式共用同一路径。

## 检测规则（行级，按优先级）

1. 已有 `#` 标题 → 原样；文件已有任一 `#` 时不再补文档大标题。
2. 粗体行（`**`…`**`，或粗体+尾随正文）：
   - 粗体内匹配样式 → 按样式层级提升；句号切标题，粗体内剩余+尾随正文按原
     顺序直连为正文段（无损）。
   - 首个非空行整行粗体（≤80 字）→ 文档大标题 `#`；粗体闭合后尾随
     （文号）单独成行保留。
3. 整行样式（`一、发展现状与形势`，≤50 字，不以列表标点收尾，无 ≥2 个内联
   数字枚举）→ 对应层级。OCR txt 块中间的标题行由此捕获。
4. 无粗体粘连：样式后到首个 `。` 的短语 ≤30 字且剩余正文 ≥15 字 → 拆分
   （`（一）指导思想。以习…` → `### （一）指导思想` + 正文）；正文过短则
   整行作标题（对齐 chunker）。
5. 第X条特例：编号后直连正文（`第一条为完善…`，规章惯例）→ 标题取
   `第X条`、其余全部为正文，不受 15 字下限（`第十条下列行为…：` 短引语须
   独立成段）；空格+短词（`第三十条 附则`）整行作标题；空格+完整句
   （`第四十四条 本办法自…施行。`）→ 编号+正文。
6. 文档大标题（文件无 `#` 时）：前 8 个非空行内，含关键词（关于/《/的通知/
   办法/规划…）≤60 字；两行拼接：机构行+关于行（`中共中央 国务院` +
   `关于…的意见`）、OCR 断行（`…关于印发` + `《…》的通知`）。
7. 列表项拒绝：`（一）采取造假…的；`（无句号、以 ；/，收尾、或首句超长）
   不提升；数字枚举 `1.`/`（1）` 永不提升。

层级映射：大标题→`#`；第X章/`一、`→`##`；第X节/`（一）`→`###`；
第X条→`####`。

## 防误伤

- **目录区**：连续 ≥3 个「短样式行」（中间仅隔空行）全部视为目录不提升
  （只统计 ≤50 字样式行——章条文档的长条文行不会把章/条串成目录）；点
  引导符（含 ASCII 句点串 `….22`、`····`、`…`）或 `|页码` 后缀的行单独拒绝。
- **保护区**：YAML frontmatter、```/~~~ 围栏内部原样。
- **守卫字符**：`< { | # [ \` ! - > = — * _ +` 开头的行不作大标题候选
  （表格/图片/代码/分割线/列表/斜体）；JSON 行、`<图片内容>` 标记、页码、
  OCR 噪声一律不动（噪声清理明确不在本期范围）。
- **中段粗体**：非粗体行不做 `**` 剥离（`加强**一、**类项目` 不伪造前缀）。
- **嵌套标题**：`**二、目标**　（一）xxx。正文` 拆出的正文若再以样式开头，
  递归再拆（单遍收敛，保证幂等）。

## 无损不变量与幂等

复原只：加 `#` 前缀、删标题上的 `**`、删标题行尾列表标点（；，、：）、
增删空白、吞并拆分点句号。`_strip_markup`（去 `#`/`**`/全部空白）归一化后
输入输出相等（容许上述两类标点）——是测试的强断言。已复原/已有 `#` 的输入
逐字节原样返回（幂等），Chai 重传 result.md 无二次改写风险。

## 验收（2026-08-28，已完成）

- 单测：`tests/test_text_titles.py` 23 个单元用例（逐规则）+ 8 件真实样例
  集成（`tests/fixtures/textmd/`，代表：粗体公文粘连/纯粗体标题/纯文本短文/
  两行拼接标题/章条规章/frontmatter+#/OCR txt/已有 # index）；
  serve 层新增 4 个接线用例（复原/GBK/解码失败回退/txt 复原），既有直通用例
  更新语义后保持通过。
- 批量：`scripts/_batch_text_titles.py` 跑 data_files 全部 193 个 md/txt：
  **零异常、零无损违规、零幂等违规**，150 件产出标题。
- 超长标题（>45 字）人工复核后仅余多部门联合发文的合法长标题与
  「已有 `#` 内含粗体」的不改动行。

## 已知边界（不处理）

- OCR txt 的 `<图片内容>` 标记/`<img>` 行/页码/句中断行不清理（本期仅标题）。
- FAQ 类问答文本（无编号样式）不产标题（保守放行）。
- `（一）` 短列表项恰好 ≤50 字且无句号结尾时仍会误提升——真实语料中未出现。
